# Crafty Witch Cove

A simple storefront landing page for selling handcrafted shampoos, conditioners, and beauty products.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

> If you see a `Not Found` page, make sure the command is run **inside this project folder** (`/workspace/CWC`) and that you open exactly `http://localhost:8000/`.

## Features

- Hero section and brand messaging
- Product grid with pricing and add-to-cart actions
- Slide-out cart with running total
- Email signup form
- No external product image dependencies (works without image CDN access)
